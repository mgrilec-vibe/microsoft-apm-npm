# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use this repository's **Report a vulnerability** flow to submit a private report.

Include the affected package version, a minimal reproduction, the impact, and any suggested mitigation. Avoid publishing proof-of-concept exploits or sensitive data.

## Scope

This policy covers the `@mgrilec/apm` package, its release workflow, and the source code in this repository.

## Supported versions

Security fixes are made for the latest published version.
